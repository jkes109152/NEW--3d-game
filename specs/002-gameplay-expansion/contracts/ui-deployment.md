# 介面、出戰與部署契約

## 畫面路由與輸入所有權

保留 slot_select、profile_menu、settings、pause、result_success、result_failure、save_error、delete_confirm、recover_confirm、rebirth_confirm；增加 store（帶 category/filter/page）、weapon_customize、prepare_armor、prepare_weapons、prepare_deployment、prepare_confirm。

- `GameController.start()` 改為 `begin_preparation()`，不再直接建 BattleState；AppState 提供 begin_preparation、set_draft_armor、set_draft_slot、place_turret、move_turret、remove_turret、back_preparation、cancel_preparation、confirm_and_start。
- 每次換路由增加既有 UI generation，舊按鈕與延遲輸入不能提交新畫面；每次有效交易配置 operation_id，保存重試沿用同一 ID。
- 按鍵先交目前畫面與對話框；戰鬥輸入只有 battle／active 有效。全域仍追蹤實體滑鼠放開以清除 held 防護，不能因位於暫停選單而漏掉 release。
- Esc 於戰鬥暫停、準備返回上一步、確認畫面回部署；準備第一步 Esc 取消整個草稿回主選單。保存錯誤頁不得用 Esc 丟掉未保存成果。
- Space 僅在主選單開始準備；Enter 啟動目前聚焦按鈕，不能在任意頁面直接出戰。數字鍵 1～5 在戰鬥切槽、選檔選欄位，其他頁不觸發購買；移除舊十商品數字購買捷徑。

## 商店與武器自訂

- 頁首固定四分類：自身升級、裝甲、自動防禦、槍枝；金幣顯示於固定位置。槍枝另有七類篩選與「全部」。
- 1280×720 與 1920×1080 均採每頁 3 欄×2 列卡片，依穩定商品 ID 排序；上一頁／下一頁有可點擊按鈕並顯示頁碼，切分類回第一頁。
- 卡片顯示名稱、輪廓預覽、射擊模式／定位、關鍵數值、價格或持有狀態。未購武器顯示購買與預覽；已購武器顯示自訂，不顯示裝備按鈕。
- 自訂頁左側旋轉／放大模型，右側分為升級、配件、外觀頁籤；顯示基礎、目前及下一級／選用後能力差異，所有數值從同一解析函式產生。
- 購買配件／外觀只解鎖；選用後按「套用自訂」以一筆 customize_weapon 保存。返回未套用時丟棄選用草稿，已完成的購買保留。
- 裝甲卡片列全部六種屬性，塔卡片列目標類型、射程、傷害、單台價格與庫存量。r=0 可預覽但購買顯示首次重生後開放。
- 原有瞄準輔助、白框、鎖定與冷卻商品移到每把適用武器自訂頁；自身分類只保留血量升級。

## 三步準備與最終確認

1. 裝甲頁：六件與「不穿裝甲」選項，只允許已擁有者；顯示角色預覽及本關有效生命／移速／回血資訊。
2. 武器頁：五個有順序槽位與已擁有卡片，先選槽再選武器，提供清空及左右換位按鈕。重複、未擁有、缺空地用途時顯示明確原因；至少兩把、至多五把。
3. 部署頁：鳥瞰地圖、逐台庫存、已部署／2r 數字、操作說明、射程預覽、返回與下一步；即使 r=0 仍可看地圖並以零部署繼續。
4. 確認頁：列裝甲、五槽、塔數及目前關卡，提供「開始戰鬥」與返回。重新驗全部規則，保存確認配置成功後建立一次當局；連點不能建立兩局。

準備草稿對 Profile 不產生金幣或庫存異動；返回前一步保留，取消整個準備還原最近確認配置。保存錯誤恢復依 [保存契約](save-transactions.md)，不自動開戰。

## 鳥瞰相機與地圖座標

- `DeploymentView` 位於 scene 呈現層，進入時記錄鏡頭 parent、position、rotation、透視／正交、fov 與滑鼠捕捉狀態；離開必須還原，不能影響下一次戰鬥瞄準。
- 世界 Y 向上；鳥瞰位置 `(center_x, 220, center_z)`、rotation `(90,0,0)`，中心起始 `(0,80)`。正交可見高度初始 200，縮放限制 40～360，滾輪每格倍率 0.9／倒數；地圖邊界 X=-60～60、Z=-80～240。
- WASD 以 `可見高度×0.5` 世界單位／秒平移；中心限制在地圖內。滑鼠中鍵拖曳以近遠點射線與 Y=0 的交點差平移，縮放後仍使用同一投影。
- 螢幕點轉換採實際渲染 viewport 的標準化座標與目前 lens.extrude，再轉成世界座標；不把 sidebar 上的點擊當地圖放置，不直接用螢幕像素假裝世界座標。
- UI 也提供方向、＋／－、置中、移除與取消按鈕；Delete 移除所選塔、右鍵取消當次放置。選取已放塔後再點地面為移動；取消移動還原原位置。
- 防守範圍與模型不因鳥瞰鏡頭縮放而改變；預覽與實際部署共用完全相同 X、Z，不另做隱藏格點吸附。

## 純部署驗證

`WorldDefinition` 提供地圖邊界、ground_y、player_spawn、world_boxes、enemy_route；源自既有 config，呈現碰撞器與規則都從此建立，不各自抄常數。

`validate_placement(world, position, other_deployments) -> PlacementResult` 回 valid、reason、position；依序檢查有限數值、地圖內縮 1.5、塔圓占地與世界障礙、出生區、必要通道與其他塔。

- 塔半徑 1.5；塔對塔中心距離至少 3，等於 3 合法。
- 障礙物採 XZ 矩形至中心的最近距離，圓占地與障礙相交或相切都非法。
- 出生點禁區半徑 3 加塔半徑 1.5，中心距離必須大於 4.5；路線各線段必要通道半寬 2 加塔半徑，點到線段距離必須大於 3.5。
- 移動某台時排除自己的舊位置；同一 instance 只能出現一次。容量驗整份草稿、不只驗單次新增。
- 錯誤碼為 invalid_position、outside_map、blocked_ground、spawn_reserved、route_reserved、overlap、capacity、not_owned、duplicate_instance，皆有繁體中文對應。

射程圈按塔的水平射程畫出；地面可見預覽從塔槍口高度 1.2 查往標準普通敵人中心高度 0.95，採 72 個角向、每徑 16 點的可見性樣本區塊，標示為近似遮擋預覽。實際攻擊仍對當下目標受擊中心精確查詢同一 visibility 函式；防空頁明示「水平範圍，實際可射仍取決於目標高度與遮擋」。不以取樣預覽作傷害判定。

## 戰鬥 HUD

- 左上玩家生命、裝甲與回血；右上城市生命及受襲；上方關卡、敵機／敵兵數；下方五槽、持用武器名稱、模式、彈匣或火箭配額、換彈／上膛、冷卻。
- 防空瞄準框依目前武器，狙擊鏡依 category；普通準心、狙擊鏡與防空框互斥。鏡頭有效倍率來自 BattleLoadout，不能固定認為槽 2 是狙擊。
- 維持目前 HUD 每 0.05 秒更新文字的節流，滑鼠瞄準與射擊事件每幀呈現；高射速不需每顆子彈重建整個 HUD。
- 兩解析度以固定比例安全區、實際字串量測及卡片分頁驗證，不縮小到不可讀。鍵盤焦點可走遍所有可操作按鈕，滑鼠可完成全部功能。
