## 摘要

在既有可遊玩的 Python 桌面專案上改造，保留純規則、Ursina 呈現、五欄位安全保存與啟動器。新增商品目錄、個別武器運作、裝備配置、準備草稿、火箭掃掠及部署幾何，讓二十種武器、六種裝甲與三種砲塔透過共用規則運作。全遊戲原創糖果風美術使用相同商品模型工廠供商店、預覽及戰鬥；商品數值一律承接 balance，不在 UI 或效果中另算傷害。

新版 Profile v2 只使用獨立資料目錄；重生清空全部付費成果，保留歷史與設定並重發三把基礎武器。所有出戰配置先驗證及保存，成功後才建立當局。已有 001 程式與驗收記錄保留為歷史基準，衝突舊測試按契約對照更新。

## 技術背景

**語言／版本**：Python 3.12.x；本機已驗 3.12.13、64 位元。

**主要依賴**：沿用 requirements-game.txt：ursina 8.3.0、panda3d 1.10.16、panda3d-gltf 1.3.0、panda3d-simplepbr 0.13.1、pillow 12.3.0、pyperclip 1.11.0、screeninfo 0.8.1、sswg 4.3.0、typing_extensions 4.16.0。pip check 已通過；不新增正式依賴。

**儲存**：UTF-8 嚴格 JSON Profile v2，`%LOCALAPPDATA%/AirDefenseQualityV2/slot-1.json`～`slot-5.json` 與 settings.json。使用 `AIR_DEFENSE_V2_SAVE_DIR`／顯式 root 注入隔離測試位置；不讀寫舊版根目錄。原子保存及完整操作歷史保留。

**測試**：標準庫 unittest、compileall、引擎與性能探測工具，另有新版商品／經濟／生命週期探測。設計階段 82 項既有測試為歷史基準；本次實作後 133 項測試、編譯與依賴檢查均通過，完整命令及退出碼見 [驗證紀錄](../../artifacts/002-gameplay-expansion/verification.md)。

**目標平台**：Windows 10+ x64 桌面，1280×720 及 1920×1080；正式遊玩離線，支援中文路徑、無音訊及低畫質。

**專案類型**：單一桌面遊戲套件，純規則與引擎呈現分離；沒有 HTTP API、帳號、多人、付款或外部伺服器。

**效能目標**：A=4 中畫質 1280×720 暖機 10 秒、量測 60 秒，平均≥55 FPS、P1≥45 FPS，無連續兩幀各超過 250 ms；A=8／12 塔與全自動／雙火箭混合量測 60 秒，活動效果不持續累積，結束回基準。十輪生命週期驗證獨立執行。

**約束**：120 Hz 固定步、每幀最多八步，時間／亂數／ID／保存位置可注入；商品數值先定案、呈現不決定命中。重生不保留付費戰力或外觀。全部 SDD 說明使用繁體中文。

**規模／範圍**：20 武器、6 裝甲、3 砲塔、5 出戰槽、5 新版欄位；初始七關與無新增硬上限的 2r 砲塔容量；四種飛機、下降／地面敵兵及 Boss。沿用編隊生成至少驗至 A=19，FAST 保留專門驗收情境。

## 第 1 階段：架構與設計

### 資料流與責任

1. `catalog.py` 定義唯讀商品、模式、配件與效果；`loadout.py` 由 Profile 與目錄解析個別能力及不可變 BattleLoadout。
2. `progression.py` 保留戰役／獎勵入口，加入 DifficultySnapshot 與十二類業務交易；`save_data.py` 驗 Profile v2、原子保存與復原，不讀舊資料。
3. `preparation.py` 管理草稿，`deployment.py` 提供純幾何與可見性；AppState 控制準備、保存後開戰、失敗原關重試與重生。
4. Controller 將有順序的輸入送入固定步；`weapons.py` 管彈匣／換彈／點放／發射時刻，`combat.py` 管鎖定／射線／傷害，`projectiles.py` 管火箭掃掠與爆炸。`entities.py` 保留向量與世界實體，補有效最大生命與具名飛行能力。
5. BattleState 回傳快照及有序事件；`scene.py`、`ui.py`、`audio.py` 只消費。鏡頭及 HUD 讀有效倍率與 weapon_id，不再寫回戰鬥能力。
6. `visual_catalog.py` 的造型配方供 `models.py` 建立原創圓潤幾何；縮圖、自訂及第一人稱共用工廠。核心射擊效果與額外粒子分開分配，避免效果池滿時整把槍沒有彈道。

### 介面與資料契約

- [data-model.md](data-model.md)：13 欄位 Profile v2、OwnedWeapon、逐台砲塔、配置、當局武器與投射物型別。
- [保存與交易](contracts/save-transactions.md)：十二種業務命令、profile／輪次戳記、指紋去重、保存失敗續接及舊檔隔離。
- [戰鬥模擬](contracts/combat-simulation.md)：有序輸入、每步優先序、射空／點放／換彈、投射物掃掠、霰彈來源及事件。
- [介面與部署](contracts/ui-deployment.md)：四商店、三步準備、六卡片分頁、正交投影、幾何邊界與 HUD。
- [呈現與驗證](contracts/presentation-validation.md)：二十武器輪廓配方、共用工廠、效果／音效、啟動器與探測工具參數。
