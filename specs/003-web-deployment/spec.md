# 003 網頁版與正式部署

使用者要求：以 Sites 將既有防空遊戲轉為網頁版並串接自購網域。

## 契約與架構

- Python 純規則透過 Pyodide 在瀏覽器執行，不重寫戰役、武器、經濟、命中或重生數值。
- Three.js 提供 3D 呈現；React 與既有 Shadcn 元件提供選檔、商店與出戰準備。
- 五個欄位保存於各網址 origin 的 localStorage，前綴 candy-defense-web-v2；桌面存檔不讀取、不覆寫。
- 保存前沿用嚴格驗證；失敗交由原本 PendingSave 保留候選結果並重試。損壞資料保留原文，使用者可以改用其他欄位。
- 桌面鍵鼠對應原版；瀏覽器失焦、切頁或離開 pointer lock 時暫停。提供觸控移動、視角、射擊與瞄準。
- 保留桌面程式。瀏覽器載入需要網路；不宣稱離線或跨瀏覽器共用存檔。
- 正式網址使用 game.jkesbyebye.com，避免覆寫現有主站、www 與郵件紀錄。
