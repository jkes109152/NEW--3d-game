# 多人合作與固定部署工作區

使用者要求：多人入口先設定名稱，再建立或加入房間；敵人與每人完整獎勵都隨新增玩家乘以 1.5，不瓜分；部署頁面不能再上下捲動。所有玩家文字使用繁體中文，每次修改同步 GitHub 與 Sites。

## 行為

- 主選單新增多人遊戲；伺服器保存匿名玩家名稱，以 HttpOnly 同站 Cookie 識別此瀏覽器。不新增密碼、第三方登入或跨裝置帳號合併。
- 房間 2–4 人，所有成員完成準備後由房主開始。成員可使用現有已確認裝備，或回到四步準備重新配置。
- 房主的 Python 模擬負責一份共同世界。每人有獨立生命、武器、彈藥、射擊與鎖定；城市、敵人、導彈與砲塔共用。玩家只發送操作，其他成員不能發布戰場或結算。
- 以開始時人數固定倍率 `1.5 ** (人数 - 1)`。敵機總數向上取整，每人以自己的單人獎勵（包括自己的重生倍率）乘上人數倍率並向下取整；兩名新玩家在 1-1 各得 187 金幣。
- 合作關卡獨立於單人關卡游標。關卡範圍依隊員共同可玩的範圍，較低進度新成員加入可能重設到可用關卡。
- 伺服器保存逐局逐人獎勵收據，單一玩家獎勵不與其他人瓜分。玩家存檔採原本瀏覽器保存；收據只有在該存檔成功寫入後才確認，漏接結算可補領，同局重送不可重複領取。
- 房主暫停會暫停全房，其他玩家只暫停自己的操作。全員倒下才因玩家生命判負。房主離開、重新載入或離線逾時會關閉房間，不宣稱房主移轉。已離開的玩家停止操作並退出當局戰力。
- 部署面板、地圖與返回／下一步位於固定視窗；三種砲塔以分頁切換，已部署砲塔以下拉選取，保留庫存、移除、圖示、平移與縮放。下拉選單可捲動選項，部署頁面本身沒有垂直捲動。

## 技術邊界與驗證

- Sites D1 儲存房間、成員、短期同步狀態及獎勵收據；prepared statements、房間成員檢查、房主權限、同站請求檢查、固定上限與單調序號限制操作。
- 使用 HTTPS 輪詢同步，房主每畫格模擬，遠端視角立即預測、物件位置平滑接近共同狀態。可靠命令重送與累積視角避免漏過一次輪詢就遺失射擊／轉向。網路延遲仍會影響遠端命中回饋。
- 房主為權威，沿用可由玩家修改的本機存檔；本版本不是伺服器反作弊系統，沒有聲稱可阻止惡意房主造假。
- 單元驗證：共同世界只推進一次、獨立操作／生命／彈藥、共同命中、完整獎勵、重送與遭竄改的獎勵歷史拒絕。
- HTTP 與 Pyodide 整合：獨立玩家身分、建立／加入、未準備阻擋、非成員／非房主拒絕、共同實體與輸入、逐人收據、重送不加倍、下一局重設準備。
- 傳輸測試：略過一次接收後命令仍完整、累積視角可恢復、暫停清除待發射命令、重新連線序號不倒退。
- 保留既有單人規則、輸入、部署與瞄準測試。沒有將 HTTP／純程式整合宣稱為瀏覽器實機操作或跨網路效能驗收。
