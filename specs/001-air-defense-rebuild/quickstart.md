# 3D 防空守衛驗證快速開始

本指南用來驗證 [spec.md](spec.md) 的主要流程；資料欄位與保存錯誤語意見 [data-model.md](data-model.md) 與 [contracts/save-schema.md](contracts/save-schema.md)。

## 前置條件

- Windows 10 或更新版本，具可用的 Python 3.12.x；建議使用 64 位元 Python。
- 可開啟原生 3D 視窗的圖形驅動；無法開窗時仍可執行純規則測試。
- 首次安裝依賴需要網路或已準備的套件快取；後續遊玩不需要網路。
- 專案路徑可含空白與繁體中文。

## 首次啟動

1. 將專案解壓到任意路徑。
2. 雙擊 `start_game.cmd`。
3. 確認專案根目錄建立 `.venv`，啟動器使用其 Python，沒有修改系統 PATH 或 PowerShell ExecutionPolicy。
4. 在五存檔畫面選擇空欄位，進入主選單，確認下一關為 `1-1`。
5. 按開始進入戰鬥；離開遊戲後再次雙擊啟動器，確認可在無網路狀態啟動已建立環境。

若 Python 不存在、依賴下載失敗或圖形能力不足，保留啟動器輸出的錯誤日誌；不要將該環境標為完整驗收通過。

## 純規則與整合測試

```powershell
.\run_tests.cmd
```

預期結果：退出碼為 0，測試輸出涵蓋 T01～T22，並使用隔離測試 Profile。至少應能以固定亂數與受控時間驗證：

完整逐項對照見 [acceptance-matrix.md](acceptance-matrix.md)；每個 T 編號都必須有對應測試名稱與證據路徑，不能只以整體測試通過推論。

- A=2、3、4、5、19 的戰役生成、編隊、獎勵與無效 a-b 拒絕；
- 鎖定衰減、導彈固定 target_id、掃掠命中與重複傷害防護；
- 武器合法目標、12／12.01、32／32.01、180 距離與遮擋邊界；
- RPG 半徑、砲塔 Boss 半血下限、回血額度、商店與重生交易冪等性；
- 五欄位隔離、損壞／未知版本、原子寫入失敗與刪除取消；
- 暫停／失焦時間停止、十次開始／結束清理與 E/G 無作用。

## 正常輸入垂直切片

使用滑鼠與鍵盤完成一次 1-1：

1. 在主選單按開始；確認 WASD、滑鼠、Space、Esc 可用。
2. 按右鍵進入普通防空瞄準，觀察白框、紅色進度與綠色可發射狀態。
3. 鎖定並以左鍵發射導彈；確認目標被擊落後其他飛機仍前進。
4. 觀察降落傘下降約 4 秒，切換狙擊槍或手槍命中下降／地面敵兵。
5. 清除全部敵人後確認只結算一次並回主選單；檢查金幣與下一關摘要。

## 完整手動畫面驗收

分別以 1280×720 與 1920×1080、視窗與全螢幕檢查：

- 五存檔選擇與刪除確認；主選單、十項商店與重生條件／結果；
- HUD 的玩家／城市 HP、警報、關卡、敵人數、武器 CD、RPG 彈藥與金幣；
- 普通炮新版／舊版瞄準、多人炮多機鎖定與每枚導彈固定目標；
- 狙擊、手槍、RPG、砲塔合法命中與空地混合戰；
- 飛機撞城、玩家死亡、城市被攻陷三種失敗；
- 音量、滑鼠靈敏度、畫質、降低動態效果與失焦暫停。

每個流程將真實截圖與操作步驟放到 `artifacts/`，並在 `docs/ACCEPTANCE.md` 標示自動情境、實際輸入或尚未完成。

## 效能與清理驗證

記錄硬體、解析度、畫質、測試時長、平均／最低 FPS 與 frame time：

1. 中畫質 1280×720、A=4：暖機 10 秒後量測 60 秒，平均 FPS 必須至少 55、P1（最差 1%）frame time 對應 FPS 必須至少 45，且不得出現連續兩個以上 frame time 超過 250 ms 的持續卡頓。
2. A=8、6 台砲塔、空地敵人與大量投射物同時存在，連續量測 60 秒並以 1 秒取樣確認投射物／特效活動計數不呈單調增加，結束後回到基準。
3. 正常開始／結束小關十次，記錄活動實體（`active entities`）、排程回呼（`scheduled callbacks`）、導彈（`missiles`）、特效（`effects`）與輸入處理器（`input handlers`）；第十次結束值與基準差異必須為 0，固定資源快取另列。
