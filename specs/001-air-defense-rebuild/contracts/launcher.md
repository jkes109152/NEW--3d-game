# 啟動與測試入口契約

這個桌面遊戲沒有對外網路 API；本文件定義玩家與開發者可直接呼叫的兩個 Windows 入口。

## `start_game.cmd`

### 輸入

- 從任意目前工作目錄雙擊或以命令列呼叫。
- 不依賴參數；路徑可能含空白或繁體中文。

### 行為

1. 解析批次檔自身目錄為專案根目錄。
2. 檢查可用 Python 3.12.x；找不到時顯示繁體中文安裝指示並以非零退出碼結束。
3. 若 `.venv` 不存在，建立專案專用虛擬環境；不得修改系統 PATH 或 PowerShell ExecutionPolicy。
4. 若依賴鎖定檔尚未安裝或版本摘要不符，安裝 `requirements-game.txt`；安裝失敗需保留錯誤日誌且不假稱啟動成功。
5. 使用 `.venv\Scripts\python.exe -m air_defense.main` 啟動遊戲。
6. 遊戲結束後傳回實際 Python 退出碼；啟動錯誤視窗不得立即消失。

### 結束碼

| 代碼 | 意義 |
|---:|---|
| 0 | 遊戲正常結束 |
| 2 | 找不到合適 Python |
| 3 | 建立或安裝 `.venv` 失敗 |
| 4 | 依賴檢查失敗 |
| 其他 | 遊戲程序的原始錯誤碼 |

已建立且依賴摘要未變時，後續啟動不得為了檢查而強制連線或重新下載。

## `run_tests.cmd`

### 輸入

- 從任意目前工作目錄雙擊或命令列呼叫。
- 可接受額外測試參數，未提供時執行完整純規則與整合測試集。

### 行為

- 使用與 `start_game.cmd` 相同的 `.venv` Python；必要時先建立與安裝環境。
- 將測試保存根目錄指向隔離的暫存／Profile 目錄，不讀寫 `%LOCALAPPDATA%/AirDefenseQuality`。
- 執行語法檢查與測試，將完整輸出留在 `artifacts/` 的驗證日誌。
- 傳回測試執行器的真實退出碼，不把缺少依賴或測試失敗轉成成功。

### 結束碼

| 代碼 | 意義 |
|---:|---|
| 0 | 所有要求的檢查通過 |
| 1 | 測試或語法檢查失敗 |
| 2 | 找不到合適 Python |
| 3 | 測試環境建立／依賴安裝失敗 |
