# 功能規格：3D 防空守衛完整重建

**功能分支**：`001-air-defense-rebuild`

**建立日期**：2026-09-05

**狀態**：可開始實作

**輸入**：使用者描述：建立可完整遊玩的 Windows 桌面第一人稱 3D 防空遊戲「3D 防空守衛」，依附件重建全部玩法、成長、存檔、品質與交付要求。

## 使用者情境與測試

### 使用者故事 1－建立或載入防守檔案並開始戰役（優先級：P1）

玩家啟動遊戲後，可以從五個獨立存檔欄位建立新檔或選擇既有檔案，查看金幣、重生次數、戰役規模與最近完成的小關，進入個人主選單並手動開始目前小關。

**優先級原因**：沒有可靠的檔案選擇與戰役入口，其他遊戲系統無法被玩家使用；這也是每次遊玩都必須成功的第一條流程。

**獨立測試**：在沒有玩家資料的環境中啟動，建立一個檔案、進入主選單、開始 1-1；重新啟動後選擇該檔案，確認摘要正確且仍由 1-1 開始。

**驗收情境**：

1. **前提** 五個欄位皆為空，**當** 玩家選擇任一欄位，**則** 系統建立初始永久資料並進入該檔案主選單，不直接跳入戰鬥。
2. **前提** 某欄位已有資料，**當** 玩家選擇該欄位，**則** 系統顯示其金幣、重生次數、A 值與最近完成關卡，且只在玩家按下開始後進入目前小關。
3. **前提** 玩家在主選單完成一個小關，**當** 結算成功返回主選單，**則** 系統等待玩家再次按開始，不自動連開下一關。
4. **前提** 玩家在欄位清單選擇刪除，**當** 玩家取消確認，**則** 目標欄位與其他欄位都保持不變。

### 使用者故事 2－進行同時存在空戰與地面戰的防守（優先級：P1）

玩家以第一人稱在城市外圍陣地移動，追蹤並擊落來襲飛機；被擊落的飛機可能釋放下降中的敵兵，玩家必須切換地面武器處理敵兵，同時阻止未擊落的飛機撞城與地面敵兵破壞城市。

**優先級原因**：空地混合戰是遊戲的核心體驗，必須讓兩種威脅同時存在且互相不會被錯誤分離。

**獨立測試**：使用固定遭遇產生一架會釋放敵兵的飛機與另一架仍在接近的飛機，實際透過滑鼠與鍵盤完成鎖定、導彈命中、敵兵下降、地面射擊與小關完成。

**驗收情境**：

1. **前提** 飛機距離玩家至少 120 世界單位，**當** 飛機沿可見轉向的接近路徑前進，**則** 玩家可在空襲危險提示出現前辨識並瞄準它。
2. **前提** 玩家擊落編隊中的一架飛機，**當** 其他飛機尚未被擊落，**則** 其他飛機繼續接近，且被擊落飛機在其當下位置建立唯一的敵兵下降批次。
3. **前提** 敵兵正在下降，**當** 玩家用合法地面武器命中它，**則** 敵兵立即消滅、停止下降且不會落地復活或攻擊城市。
4. **前提** 任一未擊落飛機到達撞城條件、玩家 HP 歸零或城市 HP 歸零，**當** 失敗條件成立，**則** 本局立即結束且不發放本局獎勵。
5. **前提** 所有飛機已擊落且所有下降與地面敵兵已清除，**當** 小關完成條件成立，**則** 系統只結算一次獎勵並返回主選單。

### 使用者故事 3－使用五種武器與自動砲塔做出合法命中（優先級：P1）

玩家可以在戰鬥所有階段切換已解鎖武器，依目標類型、距離、可見性、冷卻與彈藥規則攻擊飛機或敵兵；解鎖後的陸地自動砲塔會協助處理已落地敵兵。

**優先級原因**：武器差異、命中契約與清楚回饋決定戰術深度，也直接防止不公平或重複傷害。

**獨立測試**：對每一個武器分別測試合法目標、非法目標、距離邊界、冷卻中與遮擋情境，確認只有合法攻擊會造成傷害並消耗資源。

**驗收情境**：

1. **前提** 單目標防空炮已開啟瞄準且目標在白框內、可見、存活並完成鎖定，**當** 玩家發射，**則** 導彈以有限轉向追蹤固定目標，命中造成 1 傷害；導彈不會在目標死亡後改追其他飛機。
2. **前提** 玩家以狙擊槍、手槍或 RPG 瞄準敵兵，**當** 射線被掩體遮擋、目標超出射程、冷卻未完成或目標類型不合法，**則** 不造成傷害、不扣彈藥且不啟動冷卻。
3. **前提** 多目標防空炮框內有 12 架以上有效飛機，**當** 全部目前有效目標完成鎖定且射程合格，**則** 系統依發射快照為每架建立一枚固定目標導彈，不存在固定容量上限。
4. **前提** RPG 射線命中射程內敵兵，**當** 爆炸結算，**則** 半徑 6 內每個不同敵兵各受一次 35 傷害，飛機完全不受影響，每小關彈藥最多 3 發。
5. **前提** 自動砲塔已解鎖，**當** 小關開始，**則** 依容量建立最多 6 台砲塔；砲塔只攻擊已落地敵兵，普通敵兵需要三發，對 HP 10 的 Boss 共同維持至少 5 HP 的下限。

### 使用者故事 4－完成戰役、購買升級並選擇重生（優先級：P1）

玩家依 `a-b` 戰役順序挑戰小關，獲得金幣後在商店購買十項能力；本局失敗或完成目前戰役最後一關後，可在主選單確認付費重生並進入更大的戰役。

**優先級原因**：關卡順序、經濟與重生構成長期遊玩循環，且必須保留附件指定的數值與一次性交易行為。

**獨立測試**：以 A=2 的七關戰役完成正常與失敗流程，核對獎勵、升級費用、資格與重生後 A=3、金幣歸零及永久升級保留。

**驗收情境**：

1. **前提** A=2 且玩家開始 1-1，**當** 玩家依序完成小關，**則** 編隊與順序為 1-1 普、1-2 特、2-1 普普、2-2 普特、2-3 特特、2-4 魔特、2-5 魔魔，且每關完成後停在主選單。
2. **前提** 小關成功，**當** 結算獎勵，**則** 金幣依 `floor((100 + 25*a + 10*(b-1) + 150*boss_count) * (1 + 0.5*r))` 增加一次，重複完成事件不會重複發錢或跳關。
3. **前提** 玩家持有足夠金幣、重生資格為真且 r=0，**當** 玩家確認重生，**則** 金幣全部歸零、r 變為 1、A 變為 3、下一局回 1-1，永久升級與已解鎖武器保留。
4. **前提** 玩家未具資格或金幣少於 `1000*(r+1)`，**當** 玩家嘗試重生，**則** 操作失敗且金幣、r、A 與資格都不修改。

### 使用者故事 5－安全保存、復原與跨次啟動（優先級：P2）

玩家的永久資料可在五個欄位中隔離保存；保存成功小關、購買、重生、失敗結算與返回主選單等邊界，並在檔案損壞或寫入中斷時保留原始資料與清楚的復原選項。

**優先級原因**：長期進度若遺失或串檔會破壞信任；資料安全也是跨電腦交付的必要條件。

**獨立測試**：在隔離測試目錄建立五個欄位，模擬缺檔、損壞 JSON、未知版本、寫入中斷、刪除取消與跨欄位操作，確認資料隔離與舊檔保留。

**驗收情境**：

1. **前提** 玩家重新啟動遊戲，**當** 選擇一個非空欄位，**則** 只載入該欄位的永久資料，且當局 HP、城市 HP、敵人、導彈、冷卻、彈藥與鎖定都從新局初始化。
2. **前提** 保存檔缺失，**當** 玩家選擇該欄位，**則** 顯示為空欄位並可建立新資料。
3. **前提** 保存檔為損壞 JSON 或未知 schema，**當** 系統載入，**則** 不崩潰、不靜默覆蓋原始位元組，顯示繁體中文原因並提供備份後重建的復原路徑。
4. **前提** 保存或交易寫入失敗，**當** 玩家選擇重試，**則** 會保留記憶體中的待保存資料，且不重新扣款、不重複發獎勵。

### 使用者故事 6－以清楚的介面、音效與設定完成遊玩（優先級：P2）

玩家可以在 1280×720 與 1920×1080 使用完整繁體中文介面，辨識玩家與城市狀態、敵人剩餘量、武器冷卻、鎖定狀態與進度，並調整音量、滑鼠靈敏度、畫質、視窗模式與降低動態效果。

**優先級原因**：資訊可讀性與回饋直接影響瞄準、判斷與可及性；品質設定也要在不同電腦上維持可遊玩性。

**獨立測試**：分別以指定解析度與縮放啟動，走過存檔、主選單、商店、戰鬥、暫停與結果畫面，確認文字、按鈕、準心、音效和設定不重疊且真的生效。

**驗收情境**：

1. **前提** 玩家在戰鬥中，**當** 觀察 HUD，**則** 左上有玩家 HP／鎧甲／回血狀態，右上有城市 HP／受襲警示，上方有關卡與敵人剩餘量，下方有五武器槽、冷卻與 RPG 彈藥。
2. **前提** 普通防空炮瞄準目標，**當** 鎖定進度由未開始、累積中到完成，**則** UI 同時以顏色與文字或形狀顯示白、紅、綠狀態；新版與舊版瞄準介面不重影。
3. **前提** 玩家在戰鬥按 Esc 或視窗失去焦點，**當** 遊戲進入暫停，**則** 敵人、導彈、傷害、冷卻、回血與計時停止，恢復時不補算暫停期間的傷害。
4. **前提** 玩家關閉音訊裝置或降低音量，**當** 遊戲繼續，**則** 遊戲仍可正常操作，且武器、鎖定、命中、警報、成功、失敗與購買至少有可區分的回饋或靜音狀態。

### 使用者故事 7－以可攜方式啟動、測試與交付（優先級：P3）

玩家在含空白或中文的 Windows 路徑中雙擊啟動器即可建立專案環境、安裝固定依賴並進入遊戲；開發者可用同一環境執行測試，並取得真實截圖、效能與驗收報告。

**優先級原因**：可重現啟動與驗證證據決定其他電腦能否實際使用成品。

**獨立測試**：在乾淨或未建立虛擬環境的測試路徑雙擊啟動器，確認首次安裝、後續離線啟動、錯誤停留與測試退出碼；再檢查交付檔案清單不含玩家資料或秘密。

**驗收情境**：

1. **前提** 電腦有可用的 Python 但尚未建立本專案環境，**當** 玩家雙擊啟動器，**則** 啟動器只在專案目錄建立環境並安裝固定版本依賴，失敗時顯示可理解原因且視窗不立即消失。
2. **前提** 環境已建立且依賴版本未變，**當** 玩家再次啟動且無網路，**則** 遊戲直接離線啟動，不重複下載。
3. **前提** 執行測試入口，**當** 測試成功或失敗，**則** 入口傳回真實退出碼，且測試資料與正式玩家存檔完全隔離。

### 邊界案例

- A 值低於 2、超過允許範圍、a-b 的 b 不在公式範圍或無效編隊時，系統拒絕建立關卡，不建立半成品遭遇。
- 空的敵兵下降批次必須視為已完成；所有飛機擊落但仍有敵兵或下降動畫時不得提前結算。
- 同一目標同一更新內同時碰到導彈命中與壽命到期時，只結算一次且命中優先；高速導彈使用連續掃掠避免穿透。
- 鎖定目標離框、被遮蔽、死亡、切換武器、關閉瞄準或小關結束時，資格立即失效，進度依規則衰減或清除。
- 手槍／RPG 射程 12.0 合法、12.01 不合法；狙擊 180、砲塔 32.0 合法且超出 0.01 不合法；高度差依各武器契約使用正確距離。
- 玩家不能穿透掩體、敵人不能沿路線穿牆，玩家射線與敵人射擊都必須尊重遮擋。
- RPG 同一爆炸中同一敵人只能受一次傷害；死亡目標與飛機排除，清除最後敵人後立即重算完成條件。
- 玩家、城市或撞城飛機造成失敗後，延遲回呼、舊 attempt_id、舊導彈與舊 UI 不得污染下一局。
- 大 dt、零 dt、暫停、失焦與恢復不應造成瞬移、補算傷害或超出本關回血額度。
- 商店購買達上限、缺錢、前置未滿足、非法 ID 或重複 operation_id 時不得扣錢；滑鼠與快捷鍵必須使用同一商品目錄。
- 損壞或未知版本保存檔須保留原始位元組；刪除流程取消、重複確認或在其他畫面按鍵不得刪除錯誤欄位。
- 缺少音訊裝置、外部模型、進階 shader、中文路徑、Windows 顯示縮放或低畫質模式時仍須可啟動並提供清楚回退。
- 十次開始／結束小關後，實體、投射物、更新任務與暫時 UI 必須回到可解釋的穩定基準，不得持續增長。

## 需求

### 功能需求

- **FR-001**: 系統必須提供單機、離線、Windows 桌面第一人稱 3D 防守遊戲，核心循環為啟動、選檔、主選單、戰鬥、結算、升級與重生。
- **FR-002**: 系統必須提供五個相互隔離的永久存檔欄位；啟動先顯示欄位選擇，選擇後才進入該欄位主選單。
- **FR-003**: 主選單必須顯示下一關、開始、商店、重生、設定、返回選檔與離開；每個小關完成後必須返回主選單並等待玩家手動開始下一關。
- **FR-004**: 戰鬥必須支援 WASD 移動、滑鼠視角、Space 跳躍、左鍵攻擊、右鍵瞄準、數字鍵 1 至 5 切換、Esc 暫停與 Enter 介面操作；E 與 G必須無作用。
- **FR-005**: 場景必須提供真正的深度、透視、碰撞與第一人稱鏡頭；地圖基準為寬 120、長 320、玩家出生 `(-18,0,70)`、目標大樓中心 `(0,-60)`、城市攻擊集結點 `(0,0,-45)`。
- **FR-006**: 系統必須依 `a-b` 生成戰役；有效範圍為 `A>=2`、`1<=a<=A`、`b=1..a+1`（若 a<A）或 `b=1..2a+1`（若 a=A），總小關數為 `A*(A+5)//2`，並依規則產生普、特、魔編隊。
- **FR-007**: 系統必須實作四種可辨識飛機：普通 HP1／26 秒／0～3 敵兵、支援 HP1／34 秒／6 敵兵、快速 HP1／16 秒／無敵兵、裝甲 Boss HP5／38 秒／1 地面 Boss；四種模型與行為不可只換顏色。
- **FR-008**: 飛機必須從距玩家至少 120 的遠方沿機頭前進、可見閃避轉向的路徑接近；剩餘接近時間不超過 8 秒時必須顯示空襲危險；飛機到達撞城條件必須立即使本局失敗。
- **FR-009**: 每架被擊落飛機必須依當下位置建立唯一敵兵批次；敵兵下降約 4.0 秒（允許 ±0.25 秒），分散半徑不超過 2.5；下降中可被地面武器攻擊但不能攻擊玩家、城市或被砲塔攻擊。
- **FR-010**: 一般敵兵必須為 HP3、速度 4／秒、玩家傷害 8、攻擊冷卻 1.5 秒；地面 Boss必須為 HP10、速度 2.5／秒、玩家傷害 8、攻擊冷卻 1.5 秒；兩者沿掩體路線平順移動且不可穿牆。
- **FR-011**: 城市初始 HP必須為 100；進入半徑 10 攻擊區的每名已落地敵兵每秒造成 10 城市傷害；玩家鎧甲必須不降低城市傷害。
- **FR-012**: 系統必須實作五個武器槽：單目標防空炮、狙擊槍、手槍、RPG、多目標防空炮；前三者初始解鎖，RPG 與多目標防空炮由商店解鎖。
- **FR-013**: 單目標防空炮必須以白框內可見且存活的飛機累積鎖定；基準鎖定 3 秒，進度離框後以完整進度 0.75 秒線性歸零；完成才可發射，導彈速度 90／秒、最大轉向 240 度／秒、命中半徑 1.5、壽命 5 秒且每枚傷害 1。
- **FR-014**: 多目標防空炮必須追蹤框內所有符合條件的飛機，沒有固定鎖定數量上限；每個目標有獨立進度，只有全部目前有效目標完成鎖定且水平距離不超過 180 時才能以不可變快照各發射一枚導彈。

### 主要實體

- **玩家檔案**：五個獨立欄位之一，保存金幣、重生次數、戰役規模、永久升級、武器解鎖、重生資格與歷史摘要。
