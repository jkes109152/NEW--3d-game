# 本地程式碼審查與修正紀錄

日期：2026-09-06。使用者已回報人工遊玩測試通過。

本輪檢查本地遊戲規則、存檔與交易、介面、音訊、場景、啟動器及測試工具。由於目前程式檔案尚未納入 Git 追蹤，審查直接閱讀現有檔案，並非僅檢查 Git 差異。

## 發現與修正評估

以下問題會影響資料安全、遊玩正確性或故障處理，均已直接修正。

| 優先級 | 問題與影響 | 修正位置與結果 |
|---|---|---|
| P1 | 同欄位的其他舊刪除憑證仍有效，可能刪除重新建立的紀錄。復原流程重用遭破壞的備份時，可能失去完整原始壞檔。 | `air_defense/save_data.py`：刪除時撤銷同欄位全部憑證；復原前核對備份內容雜湊，不符則重新備份。 |
| P1 | 寫入失敗後切換欄位可能丟棄尚未保存的進度。 | `air_defense/state.py`：待保存交易存在時禁止切換欄位，保留重試所需狀態。 |
| P2 | 無效交易目的欄位或請求可能先改動記憶體資料；過期戰役獎勵衝突仍會改寫交易歷史。 | `air_defense/save_data.py`、`air_defense/progression.py`：先驗證目的欄位、資料與請求結構，衝突直接返回且不改動紀錄。 |
| P2 | 射線命中掩體上方露出的頭部，仍因敵人中心被遮擋而判定失敗。 | `air_defense/combat.py`：地面射線攻擊使用實際命中點檢查遮擋。 |
| P2 | 城市失守後同一敵人仍可能傷害玩家；不足一個固定步長的輸入幀可能丟失瞄準切換。 | `air_defense/state.py`：失敗立即停止敵人更新；保留待處理瞄準狀態，較新的明確輸入優先。 |
| P2 | 畫質切換未覆蓋合併模型內的舊著色狀態；低畫質可能失去頂點配色。音量調整還會重設陰影範圍。 | `air_defense/scene.py`、`air_defense/main.py`：清除模型殘留著色狀態，統一套用材質；低畫質保留頂點色，畫質未變時不重設陰影。減少動態效果時還原武器後座位置。 |
| P2 | 音訊裝置失效時，查詢聲音狀態或停止播放可能使主迴圈中斷。 | `air_defense/audio.py`：捕捉裝置錯誤，清理音效並切換靜音，保留錯誤資訊。 |
| P2 | 既有虛擬環境缺少 pip 無法自行修復；使用最佳化 Python 時，原本的 assert 版本檢查可能被略過。 | `tools/bootstrap.py`：安裝前檢查及修復 pip，改用明確退出碼驗證版本，安裝後再次驗證。 |
| P2 | 刪除憑證失效仍顯示成功；刪除失敗後介面保留不能重用的憑證。 | `air_defense/main.py`：依實際結果顯示提示；失敗或失效後清除憑證，返回欄位選擇。 |

另修正離屏引擎測試的滑鼠捕捉與介面投影初始化，使驗證能在不操作使用者桌面的情況下執行；補齊 `assets/LICENSES.md` 的隨附繁體中文字型來源及授權登記。
